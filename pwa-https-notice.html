需要安全连接

问题：投篮教练需要通过HTTPS安全连接访问摄像头。当前您使用的是不安全的连接。

为了保护您的隐私，现代浏览器要求通过安全连接（HTTPS）才能访问摄像头。

解决方案：

  1. 部署到支持HTTPS的服务器：
    • Vercel (推荐): vercel.com
    • Netlify: netlify.com
    • GitHub Pages: pages.github.com
  2. 本地测试（仅限开发）：
    • 使用 localhost 而不是IP地址
    • 或使用 ngrok 创建HTTPS隧道

部署后，您的应用将自动获得HTTPS证书，摄像头功能即可正常使用。
